# 0003. 툰 렌더 파이프라인

- 상태: 채택
- 날짜: 2026-11-20
- 대체: [0001](0001-ps1-render-pipeline.md)

대상·파일명 규칙: [docs/rules/architecture/overview.md](../rules/architecture/overview.md#adr)

## 배경

2026-11-20 사용자가 PS1 레트로를 버리고 툰 셰이딩으로 전환하기로 결정했다. 저해상도(240x320) 렌더타깃과 디더·15bit 양자화는 외곽선과 밝은 평면 색의 가독성을 해치고 고해상도 모바일 화면에서 흐릿하게 보였다.

## 결정 기준

1. 모바일 60fps 유지
2. 의존성은 three 하나
3. 조작 대상이 배경보다 눈에 잘 띔
4. 스냅샷 결정적
5. pick·anchor 좌표 규약 불변

## 검토한 대안

| 대안 | 장점 | 단점 |
| --- | --- | --- |
| A. 후처리 라이브러리 외곽선 | 구성이 편함 | 의존성·패스 증가로 기각 |
| B. 깊이·법선 후처리 에지 검출 | 모델 수정 없음 | 풀스크린 패스 추가, 얇은 모델 두께 불안정으로 기각 |
| C. 커스텀 셀 셰이더 | 완전한 제어 | 내장 MeshToonMaterial로 충분해 기각 |
| D. 내장 MeshToonMaterial + inverted hull 외곽선 | 의존성·패스 추가 없음, 두께 일정 | 모델당 드로콜 +1 (채택) |

## 결정

D를 채택한다.

1. 화면 해상도로 렌더한다. `pixelRatio = min(devicePixelRatio, 2)`, 안티앨리어싱을 켠다.
2. 조명은 앰비언트 + 방향광 1개, 그림자 맵은 없다.
3. `MeshToonMaterial` + 3단 `gradientMap`(`NearestFilter`).
4. 외곽선은 뒷면 메시를 위치별 평균 법선 방향으로 클립 공간에서 2 CSS px 밀어 그린다(모델당 드로콜 +1).
5. 버텍스 컬러 위주의 밝고 채도 높은 평면 색을 쓴다. 절차 텍스처는 나무결·천 체크·소스 줄무늬·후네 결만 두고, 64px 이하·외부 에셋 금지를 유지한다.
6. 구멍 테두리·배경은 무조명 `MeshBasicMaterial`이다.
7. `ColorManagement`를 끄고 색 값은 화면 sRGB 그대로 쓴다.

## 영향

- 스냅샷은 render.snapshot 뷰포트(390x844, dpr 3) 기준으로 비교한다.
- ScenePicker는 canvas rect 비율만 쓰므로 계약 변화가 없다.
- PS1 전용 사양(버텍스 스내핑, affine, 디더, 15bit)은 폐기한다.
- 번들은 약 574kB → 602kB.

## 재검토 조건

- 중저가 모바일에서 60fps 미달: 외곽선 합본·pixelRatio 상한 하향을 검토한다.
- 외곽선 두께가 모델 크기에 따라 어색함: 후처리 에지를 검토한다.
- 그림자·조명 추가 요구.
