# AI 실행 정책

## 독립 리뷰

reviewer 서브에이전트 독립 리뷰를 추가하는 조건:

- 점수·별점·평균 정확성
- contracts 변경
- sessionStorage 키·형식
- 공통 유틸·빌드·PWA 설정

- 기본: 조건 해당 여부가 불분명하면 추가한다.
- 필수: 작업 시작 시 독립 리뷰 필요 여부와 근거를 한 줄로 밝힌다.

## 자동 수정 한도

- 필수: 자동 수정은 작업 범위당 3회(자체 수정 + 독립 리뷰 후 수정 합산).
- 필수: 초과하면 중단하고 보고한다.
- 금지: 접근 방식 변경·에이전트 교체로 횟수를 초기화한다.
- 재개는 사용자 요청으로만.
