# 구현 협업

## 먼저 합의 vs 자율 진행

| 먼저 합의 | 자율 진행 |
| --- | --- |
| contracts 변경 | 모듈 내부 함수 추출·이름 |
| GDD 수치·페이즈·점수 변경 | GDD에 명시된 규칙 구현 |
| 라이브러리 추가·버전 변경 | 이미 쓰는 라이브러리 활용 |
| 폴더 소유권·모듈 경계 변경 | 담당 폴더 내부 정리 |

- 금지: 미래 기능용 추상화를 미리 만든다.
- contracts 변경 제안은 [TODO-CONTRACT.md](../../../TODO-CONTRACT.md) 양식으로 남긴다.

## 작업 루프

구현 → 실행 검증(도구) → 리뷰 → 수정·재검증.

- 금지: 테스트 통과만으로 리뷰를 대신한다.
- 자동 수정 한도와 독립 리뷰 조건은 [ai-execution.md](ai-execution.md).

## 리뷰

체크 항목:

1. 요청 누락
2. 무관한 변경
3. 경계·contracts 준수([overview.md](../architecture/overview.md))
4. 정상·실패·경계값 테스트
5. 코드·문서 일치

지적 분류:

| 분류 | 처리 |
| --- | --- |
| 필수 수정 | 완료 전 수정 |
| 합의 필요 | 사용자에게 올림 |
| 선택 개선 | 완료를 막지 않음 |

## 완료 보고

필수 항목:

- 변경
- 실제 실행한 도구·결과
- 미검증 범위
- 적용 스킬 영수증(스킬이 있을 때)

검증하지 못했으면 "구현 완료, 검증 미완료"로 보고한다.
