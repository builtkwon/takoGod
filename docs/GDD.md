# 타코야끼트럭 GDD

이 문서는 게임 규칙과 수치의 원본이다. 코드·테스트·대사 데이터는 이 문서를 따른다. 변경은 integrator 세션에서만 사용자 합의 후 수행한다.

## 제품

- 모바일 세로화면 PWA, 정적 배포(Cloudflare Pages). 백엔드·계정 없음.
- 세션 점수 = 받은 리뷰 별점의 평균. sessionStorage 저장(탭 종료 시 초기화).
- 가게 점수 = 별점과 별개의 상한 없는 점수(§가게 점수). 최고 가게 점수만 localStorage 키 `takoyaki:best`에 영구 저장한다. 값은 JSON `{version: 1, best: number}`이고 손상된 값(파싱 실패, version 불일치, best가 유한한 0 이상의 수가 아님)은 버린다(기록 없음) → [ADR 0004](adr/0004-best-shop-score-storage.md). 최고 기록은 세션이 끝날 때(결과 화면 도달) max로 갱신한다.
- 튜토리얼 완료 여부는 기기에 기억한다. localStorage 키 `takoyaki:profile`, 값은 JSON `{version: 1, tutorialCompleted: true}`이고 손상된 값은 버린다 → [ADR 0005](adr/0005-profile-storage.md). 이번 판 점수·리뷰는 아래 sessionStorage 그대로다.
- sessionStorage 키 `takoyaki:session`, 값은 JSON `{version: 1, tutorialCompleted, finished, reviews: ReviewResult[]}`(contracts `SessionSnapshot`) → [ADR 0002](adr/0002-session-storage.md). `reviews`는 contracts `ReviewResult`(source, stars, comment, personality)를 그대로 직렬화하고, 튜토리얼 리뷰의 personality는 null이다.
- 복원: 파싱 실패나 version이 1이 아니면 값을 버리고 새로 시작한다. `finished`가 true면 결과 화면을 다시 보여준다. 본게임 도중 새로고침하면 본게임 P1부터 다시 시작하고 튜토리얼 리뷰만 남긴다.
- 그래픽: 툰 셰이딩. Three.js, 화면 해상도 렌더(pixelRatio 상한 2), 3단 셀 조명(방향광 1 + 앰비언트), 모델 외곽선(inverted hull), 밝고 채도 높은 평면 색, 로우폴리. 절차 텍스처는 64px 이하만 사용하고 외부 에셋 금지. → [ADR 0003](adr/0003-toon-render-pipeline.md)

## 굽기

철판은 4×4 16구이고 구멍은 각자 독립 상태로 진행한다. 구멍 인덱스는 0..15, 행 우선(index = 행*4 + 열, 0행이 화면 위쪽)이며 내부에서만 쓴다. 전역 순서, 구멍 번호 버튼, 하단 버튼 줄은 없다. 구멍이 늘어난 만큼 알(타코야끼)과 후네는 화면에서 조금 작게 그린다. 후네는 6알 그대로다.

- 조작은 세 묶음이다.
  - 재료(마가린·반죽물·속재료): 마가린·반죽은 통에서 끌어 손가락이 지나간 구멍마다 한 번씩 칠한다(마가린은 빈 구멍, 반죽은 기름칠된 구멍만, 맞지 않는 구멍은 건너뜀). 하나도 칠하지 못하고 놓으면 통으로 돌아간다. 속재료는 놓은 구멍 하나에만 넣는다.
  - 동작: 구멍을 탭하면 굴리기 1회다.
  - 완성: 완성품은 후네(나룻배 용기)에 닿게 놓아 담는다. 후네 밖에 놓으면 떨어져 사라진다. 탄 것은 어디에 놓든 떨어져 사라지고 후네에 담기지 않는다.
- 화면 표기: 마가린 단계·도구의 화면 이름은 "버터"다(내부 이름 margarine 유지). 아래 규칙 설명의 "마가린"은 이 버터를 가리킨다.
- 배치(세로): 상단 HUD는 왼쪽 위에 최고 가게 점수, 가운데에 현재 단계(레벨)와 그 아래 현재 가게 점수, 오른쪽 위에 별 칸(이번 판 평균 별점)과 그 아래 작게 리뷰 수를 둔다(왼쪽 위에 레벨을 두지 않는다). 기록이 없으면 왼쪽 위는 "최고 -"로 보인다. 진행 중 현재 가게 점수가 저장된 최고 기록을 넘으면(기록이 없을 때는 0을 넘으면) 왼쪽 위 최고 표시 옆에 "NEW"가 반짝인다. 타이밍 바는 상단 HUD 바로 아래, 판정 글자(적중·빗나감!)는 크게 보인다. 마가린 통 철판 왼쪽, 반죽물 주전자 철판 오른쪽, 속재료 트레이 철판 아래, 후네 하단.

### 구멍 상태 흐름

| 상태 | 조작 | 판정 | 다음 상태 |
| --- | --- | --- | --- |
| 빈칸 | 마가린 놓기 | 없음 | 기름칠 |
| 기름칠 | 반죽 놓기 | 없음. 익힘 시작 | 익힘 |
| 익힘 | 3초 경과 | 없음 | 익힘 완료 |
| 익힘 | 속재료 놓기 | 거부(재료가 트레이로 돌아감) | 익힘 |
| 익힘 완료 | 속재료 놓기 | 없음 | 속재료 후 |
| 속재료 후 | 탭(굴리기 1) | 바 위치가 영역 W1 안이면 적중 | 굴림 1 |
| 익힘·익힘 완료 | 탭(속재료 전 굴리기) | "속 없음"으로 고정, 그 탭이 굴리기 1이다(판정은 W1) | 굴림 1 |
| 굴림 1 | 탭(굴리기 2) | 바 위치가 영역 W2 안이면 적중 | 완성. 탐 타이머 시작 |
| 완성 | 들기 | 없음. 탐 타이머 정지 | 들고 있음 |
| 들고 있음 | 후네에 닿게 놓기 | 없음 | 빈칸(후네에 1개) |
| 들고 있음 | 후네 밖에 놓기(화면 밖 포함) | 떨어져 사라짐(ui 연출, 판정 아님) | 빈칸 |
| 완성 | 탐 타이머 누적 4초 | 어두워짐 | 어두움 |
| 어두움 | 들기, 후네에 닿게 놓기 / 후네 밖에 놓기 | 완성과 같다(어두운 것도 후네에 담을 수 있다) | 빈칸(후네에 어두운 것 1개) / 빈칸(떨어져 사라짐) |
| 어두움 | 탐 타이머 누적 6초 | 탐 | 탄 것 |
| 탄 것 | 들어서 어디에 놓든(후네 포함) | 떨어져 사라짐. 후네에는 담기지 않는다 | 빈칸 |
| 빈칸·기름칠·완성·어두움·탄 것 | 탭 | 효과 없음, 감점 없음(헛손질 효과음) | 변화 없음 |

- 공통: 재료(마가린·반죽물·속재료) 놓기 중 표에 없는 것은 거부하고 재료는 원위치(통·트레이)로 돌아간다. 마가린·반죽은 통에서 끌어 손가락이 지나간 구멍마다 한 번씩 칠한다(마가린은 빈 구멍, 반죽은 기름칠된 구멍만, 맞지 않는 구멍은 건너뜀). 하나도 칠하지 못하고 놓으면 통으로 돌아간다. 속재료는 놓은 구멍 하나에만 넣는다.
- 떨어짐: 완성·어두움·탄 것을 후네 밖에 놓으면(탄 것은 후네에 놓아도) 놓은 위치에서 아래로 떨어져 화면 밖으로 나가며 사라지고 구멍은 빈칸이 된다. 떨어지는 연출은 판정 대상이 아니라 ui 연출이다.
- 익힘: 반죽을 놓으면 시작해 3초 뒤 익힘 완료다(초당 20씩 0→60). 익힘 완료 뒤에는 기다려도 벌칙이 없다.
- 속재료 전 굴리기: 허용한다. 그 구멍은 "속 없음"으로 고정되어 속재료를 넣을 수 없다. 접시당 -20(§점수).
- 타이밍 바: 전역 하나다. 1.6초 주기로 왕복하고 세션 내내 계속된다. 굴리기 판정은 구멍을 누르는 순간(손가락을 뗄 때가 아니다)의 전역 위치 그대로 하고 영역은 판 전체가 공유한다(아래 영역 위치).
- 영역 폭(바 전체 길이 1 기준): P1·P2는 W1 0.30, W2 0.24. P3·P4·P5는 W1 0.24, W2 0.20. 튜토리얼은 W1·W2 모두 0.50이고 위치는 가운데(0.25~0.75) 고정이다(타이밍 연습). 튜토리얼에서 빗나가도 굴리기는 진행되고(적중 기록만 false) 튜토리얼 진행을 막지 않는다. W2는 시작값이고 sim.balance 측정 뒤 조정한다.
- 영역 위치: 영역은 구멍마다가 아니라 판 전체가 공유한다. 굴리기 1용 영역 W1과 굴리기 2용 영역 W2가 하나씩 있고, 어느 구멍을 누르든 그 구멍 단계에 맞는 공용 영역으로 판정한다. 바에는 W1(표시 1)과 W2(표시 2)를 함께 보여 주며, 각 영역은 그 영역으로 굴릴 수 있는 구멍이 하나라도 있을 때만 보인다. 위치는 무작위다: 페이즈 시작 시 W1→W2 순으로 뽑고, 굴리기 1을 할 때마다(적중·빗나감 무관) W1을, 굴리기 2를 할 때마다 W2를 다시 뽑는다(영역 전체가 0..1 안에 들도록 균등 분포, seeded). 판정은 누르는 순간의 바 위치와 그 순간의 공용 영역으로 한다. 튜토리얼은 뽑지 않는다.
- 굴리기 2회 적중이 완벽 조건이다. 빗나가도 감점은 없고 그 구멍의 완벽 판정만 무효다.
- 탐 타이머: 완성 시점부터 누적한다. 들고 있는 시간과 후네가 가득 차 서빙을 기다리는 시간은 세지 않는다. 누적 4초에 어두워지고 6초에 탄다.
- 들기는 동시에 1개만 가능하다. 포인터 취소와 앱 백그라운드 전환(사용자 실수가 아님)은 떨어뜨리지 않고 원래 구멍으로 되돌리며 탐 타이머를 다시 흘린다.
- 구멍 테두리(게이지 아님): 익힘 완료 초록, 완성 흰색, 어두워짐 시작 주황. 탐 타이머가 도는 완성 구멍이 철판에 2개 이상이면 그 구멍들의 테두리가 깜빡여 경고한다.
- 판정 단위: 후네 1척(6개) = 손님 1명에게 서빙되는 1접시. 만족도 변화는 접시 단위로 적용한다(§점수).
  - 완벽 굽기 +20: 6개 모두 굴리기 2회 적중, 속재료 문어, 어두워짐 0개.
  - 속 없음 -20: 속 없음 구멍이 1개 이상이면 접시당 1회.
  - 함정 재료 -20: 함정 재료 구멍이 1개 이상이면 접시당 1회.
  - 어두워짐: 별점 상한(§점수).
- 후네: 6개가 차면 가쓰오부시가 얹히는 완성 연출을 하고 1초 뒤 가장 먼저 온 대기 손님에게 자동 서빙(선착순)한다. 가득 찬 뒤 서빙 전까지(연출 1초 포함) 후네에 놓기를 거부하고 원래 구멍으로 되돌리며(떨어뜨리지 않는다) 탐 타이머는 지금처럼 멈춘다. 예외: 손님이 0명인 페이즈(튜토리얼·P1)는 후네가 차면 1초 뒤 서빙 없이 비우고 전환한다.
- 서빙하면 후네만 비운다. 철판에서 진행 중인 구멍은 그대로다.
- 속재료 트레이: 문어 + 함정 재료(와사비, 생마늘, 지우개, 마시멜로, 고추). 서빙 시점에 위치를 셔플한다(화면 반영은 끌기가 끝난 뒤).

## 손님 대화

- 손님 발화 시 답 버튼 2개가 화면 랜덤 위치에 등장(서로·구멍·통·후네와 겹치지 않음).
- 좋은 답 +10, 나쁜 답 -10, 시간초과 -10.
- 결과 연출(판정과 무관한 ui 연출, 시드 불필요): 좋은 답이면 그 손님 위에 약한 폭죽 파티클. 나쁜 답·시간초과면 그 손님 머리 위에 물음표 또는 빠직(분노 마크) 중 하나를 무작위로 1.5초 보여 준다.
- 대화 중에도 굽기(익힘, 탐 타이머)와 손님 인내는 계속 진행된다.
- 답 제한시간 5초. 빠른 손님(6s 간격)도 같고 대화 간격만 다르다.
- 문항 선택: 손님마다 성격을 무작위로 정하고, 성격 내 문항은 세션 동안 가능한 한 반복하지 않는다. 그 성격의 문항을 모두 쓰면 사용 기록을 초기화한다. 사용 기록은 저장하지 않아 새로고침하면 초기화된다. 난수 시드는 주입할 수 있어야 한다.
- 난수 뽑기 순서: 손님 입장 시 성격 → 인내 시간, 접시 서빙 시 어두워짐 상한 → 다시해줘 → 떠남 → 떠남 별점 → 맛보기 반응 → 리뷰 코멘트 → 트레이 셔플 순이고, 조건이 맞지 않는 항목은 뽑지 않는다(다른 난수 수열을 보존). 여기에 페이즈 시작 시 W1·W2 위치, 굴리기 1 시 W1 위치, 굴리기 2 시 W2 위치가 더해진다(사건 시점, 같은 수열).
- 점수 비공개: 조리·대화 중에는 만족도 증감을 표시하지 않는다. 손님이 접시를 받은 직후 맛보기 반응 대사를 보여 주고 그 뒤 만족도 합산 결과(별점)를 보여 준다.
- 맛보기 반응: 접시의 결함 종류(속 없음, 함정 재료, 어두움, 굴리기 빗나감)마다 성격당 대사 2개 중 하나를 고르고, 결함이 없으면 "완벽" 대사를 쓴다. 예: "문어는 어디갔어!", "밀가루 뭐임!".
- 손님 인내: 손님마다 20~40초 사이 무작위(seeded)이고 입장 시점부터 센다. 경과 비율에 따라 얼굴 색이 3단계(기본 → 주황 50% → 빨강 80%)로 바뀌고 되돌아가지 않는다. 100%에 도달하면 만족도 -20을 한 번 적용하고, 손님은 떠나지 않는다. 연출: 화면이 0.4초 흔들리고, 그 손님 머리 위에 분노 표시가 뜨고, 성격별 짧은 분노 대사 2개 중 하나를 말풍선으로 짧게 보여 준다.
- 다시해줘: 접시 별점이 2.5 이하이면 20% 확률로 손님이 재요청한다. 손님 1명당 1회다. 다음에 완성한 후네를 그 손님에게 우선 서빙하고, 리뷰 별점은 다시 받은 접시 기준으로 다시 계산한다(첫 접시의 접시 증감과 상한은 취소하고 대화·인내 증감은 유지). 첫 접시에는 리뷰를 발급하지 않는다.
- 0~1점 떠남: 접시 별점이 1.5 이하이고 다시해줘가 아닐 때 15% 확률로 손님이 별점 0~1(0.5 단위 무작위)을 남기고 떠난다.
- 손님 흐름: 페이즈 시작 시 손님1 입장, 손님 2명 페이즈는 손님2가 3초 뒤 입장. 서빙받은 손님은 리뷰(만족도 → 별점)를 발급하고 퇴장하며, 다음 손님은 2초 뒤 입장한다. 모든 입장(손님2 포함)은 (이 페이즈에서 리뷰를 발급한 접시 수 + 현재 손님 수) < 페이즈 목표 접시 수일 때만 일어난다. 그래서 마지막 접시를 서빙하면 남는 손님이 없다. 예외: 손님이 0명인 페이즈(튜토리얼·P1)는 후네가 차면 1초 뒤 서빙 없이 전환한다.

## 진행

| 단계 | 손님 | 대화 간격 | 리뷰 |
| --- | --- | --- | --- |
| 튜토리얼 | 0 | - | 완수 시 5★ 리뷰 1개 확정 지급(평균 포함) |
| 본게임 P1 | 0 | - | 미집계 |
| P2 | 1 | 12s | 집계 |
| P3 | 2 | 각 12s | 집계 |
| P4 | 2 | 손님1 6s / 손님2 12s | 집계 |
| P5 | 2 | 각 6s | 집계 |

- 손님 수는 동시 손님 수다. 예: P2는 손님 1명을 순차 교체하며 2접시를 서빙한다.
- 페이즈 전환: 리뷰를 발급한 접시 수 기준. P1 후네 1척(서빙 없이 완성 수), P2 2, P3·P4·P5 각 4. P5 종료 시 세션 결과로 간다.

### 튜토리얼

- 16구 중 가운데 2열 × 위 3행의 6구(인덱스 1,2,5,6,9,10)만 쓰고 나머지 10구는 잠근다(어둡게 표시, 모든 조작 거부, 화살표 흔들지 않음).
- 화살표 + 상단 안내문구로 단계별 유도: 한 단계씩 사용 구멍 6개에 같은 조작을 하게 한다(마가린 → 반죽물 → 익힘 기다림 → 속재료 → 굴리기 1 → 굴리기 2 → 후네 담기).
- 어두워짐·탐 없음, 시간제한 없음. 익힘은 본게임과 같은 3초다.
- 굴리기 영역은 바 전체의 50%(가운데 고정)로 제시해 타이밍 바를 연습시킨다. 빗나가도 굴리기는 진행되고 튜토리얼을 막지 않는다.
- 현재 단계의 조작만 받는다. 다른 조작(속재료 전 굴리기 포함)은 거부하고 원위치시키며 화살표를 흔든다.
- 후네 담기 단계에서 후네가 아닌 곳에 놓으면 떨어뜨리지 않고 거부·원위치한다(학습 단계).
- 함정 재료는 감점 없이 경고 말풍선을 표시하고 재료는 트레이로 돌아간다.
- 완수 시 5★ 리뷰 카드 → 본게임 P1 진입.
- 기기당 1회. 완료하면 localStorage `takoyaki:profile`에 기억하고, 같은 브라우저로 다시 접속하면 튜토리얼을 건너뛰고 P1부터 시작한다. 이때 튜토리얼 5★ 리뷰는 주지 않는다(그 세션에서 튜토리얼을 하지 않았다). 같은 탭 새로고침은 세션 저장값(`tutorialCompleted`)으로 건너뛰는 동작 그대로다. 튜토리얼을 마친 기기에서는 타이틀에 "튜토리얼" 버튼이 있어 튜토리얼부터 다시 할 수 있다(이번 판 세션은 새로 시작하고 최고 기록은 유지한다). 다시 끝내면 5★ 리뷰가 새로 생긴다.

## 점수

| 항목 | 만족도 변화 |
| --- | --- |
| 시작값 | 80 |
| 좋은 답 | +10 |
| 나쁜 답 / 시간초과 | -10 |
| 완벽 굽기 | +20 |
| 속 없음 | -20 |
| 함정 재료 | -20 |
| 인내 100% 도달 | -20(한 번) |

- 만족도는 변화마다 0 아래로는 내려가지 않는다(하한 0). 상한은 없다. 별점은 clamp(만족도 / 20, 1, 5)라 100 이상이면 5★.
- 별점 범위는 0~5다. 접시 별점 = clamp(만족도 / 20, 1, 5), 0.5 단위 반올림. 0~1점(0, 0.5, 1)은 0~1점 떠남(§손님 대화)으로만 나온다.
- 어두워짐 별점 상한: 접시에 어두워진 구멍이 있으면 별점 = min(기존 별점, 상한)이다. 상한은 개수 구간의 범위에서 0.5 단위로 무작위(seeded)로 뽑는다. 어두워진 구멍이 있는 접시에서만 별점 계산 직후·코멘트 선택 전에 한 번 뽑는다.

| 어두워진 개수 | 상한 범위 |
| --- | --- |
| 1 | 3.5~4.0 |
| 2~3 | 3.0~3.5 |
| 4~5 | 2.5~3.0 |
| 6 | 2.0~2.5 |

- 세션 점수 = 모든 리뷰 별점의 산술평균(튜토리얼 5★ 포함).

### 가게 점수

별점과 별개의 상한 없는 점수다. 접시마다 더하며 세션 점수(별점 평균)에는 영향을 주지 않는다.

- 접시 기본 점수 = 그 접시의 만족도 합산이 끝난 뒤 만족도(하한 0, 상한 없음, 별점 계산에 쓰는 값. 어두워짐 별점 상한과는 무관). 손님 없는 페이즈(P1)에서 비우는 접시는 시작 만족도 80을 기본 점수로 쓴다.
- 굴리기 적중 보너스: 적중 1회당 +5(접시당 6알 × 2회, 최대 +60). 속 없음 굴리기도 적중이면 센다.
- 완벽 접시 = 완벽 굽기 조건(§굽기: 6개 모두 굴리기 2회 적중, 속재료 문어, 어두워짐 0개)을 만족한 접시.
- 콤보: 연속 완벽 접시 n번째(n≥1)는 (기본 점수 + 적중 × 5)에 배수 1.0 + 0.2 × (n−1)을 곱한다(최대 2.0). 완벽이 아닌 접시는 배수 ×1.0이고 연속을 0으로 되돌린다.
- 접시 점수 = round((기본 점수 + 적중 × 5) × 배수). 가게 점수 = 접시 점수의 합.
- 튜토리얼 접시는 가게 점수 0이고 콤보에도 들어가지 않는다.
- 다시해줘를 부른 첫 접시는 가게 점수에 더하지 않고 콤보도 건드리지 않는다. 다시 받은 접시로 계산한다(§손님 대화).
- 세션이 끝나면(결과 화면 도달) 최고 가게 점수 = max(저장값, 이번 판 가게 점수)로 저장한다. 저장값이 없으면 이번 판 점수가 최고 기록이다. 결과 화면은 가게 점수를 보이고, 최고 기록을 갱신했으면 "최고 기록!"을 함께 보인다.
- 예: 완벽 접시(만족도 100, 적중 12)가 연속 1·2·3번째이면 (100 + 60) × 1.0 = 160, × 1.2 = 192, × 1.4 = 224.

## 콘텐츠

- 손님 성격 4종: 급한 직장인, 수다쟁이 할머니, 까다로운 미식가, 외국인 관광객. 각 10문항(총 40).
- 문항: 손님 대사 / 좋은 답 / 나쁜 답. 나쁜 답은 무례하거나 엉뚱해서 웃기되 혐오·비하 금지. 두 답 길이가 비슷해야 한다.
- 맛보기 반응 대사: 결함 종류 5(속 없음, 함정 재료, 어두움, 굴리기 빗나감, 완벽) × 성격 4 × 2개 = 40개.
- 리뷰 코멘트: 별점 구간(1~5)별 성격당 3개. 0.5 단위 별점은 내림한 구간을 쓰고(4.5★ → 4 구간), 0~1점은 1 구간을 쓴다. 상한을 적용한 뒤의 별점으로 고른다.
- 분노 대사(인내 100%): 성격 4 × 2개 = 8개.
- 튜토리얼 안내문구 7개(단계별), 튜토리얼 5★ 코멘트 1개.
