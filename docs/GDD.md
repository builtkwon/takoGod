# 타코야끼트럭 GDD

이 문서는 게임 규칙과 수치의 원본이다. 코드·테스트·대사 데이터는 이 문서를 따른다. 변경은 integrator 세션에서만 사용자 합의 후 수행한다.

## 제품

- 모바일 세로화면 PWA, 정적 배포(Cloudflare Pages). 백엔드·계정 없음.
- 세션 점수 = 받은 리뷰 별점의 평균. sessionStorage 저장(탭 종료 시 초기화).
- sessionStorage 키 `takoyaki:session`, 값은 JSON `{version: 1, tutorialCompleted, finished, reviews: ReviewResult[]}`(contracts `SessionSnapshot`) → [ADR 0002](adr/0002-session-storage.md). `reviews`는 contracts `ReviewResult`(source, stars, comment, personality)를 그대로 직렬화하고, 튜토리얼 리뷰의 personality는 null이다.
- 복원: 파싱 실패나 version이 1이 아니면 값을 버리고 새로 시작한다. `finished`가 true면 결과 화면을 다시 보여준다. 본게임 도중 새로고침하면 본게임 P1부터 다시 시작하고 튜토리얼 리뷰만 남긴다.
- 그래픽: PS1 레트로. Three.js, 240x320(세로) 렌더타깃 nearest 업스케일, 버텍스 스내핑, affine 텍스처, 4bit 디더 + 15bit 컬러 양자화, 로우폴리. 64px 이하 절차 텍스처만 사용, 외부 에셋 금지.

## 굽기

순서(6구 철판, 구멍별 독립 상태):

1. 마가린
2. 반죽물
3. 살짝 익음 — 익음 게이지(덜익음 / 적정 / 탐)
4. 속재료 넣기
5. 살짝 익음 — 익음 게이지
6. 굴리기 1
7. 굴리기 2
8. 굴리기 3 — 각 회차 타이밍 판정
9. 완성

- 게이지가 적정 구간일 때 다음 단계를 눌러야 한다. 빠르면 덜익음, 늦으면 탐.
- 익음 게이지: 0에서 시작해 초당 20씩 100까지 증가하고 100에서 정지한다. 덜익음 0~59, 적정 60~85, 탐 86 이상(100에서 정지한 상태도 탐). 2회 익힘 모두 같은 수치.
- 굴리기: 회차마다 타이밍 바가 1.2초 주기로 왕복하고 40~60 구간에서 누르면 성공. 실패는 감점 없이 해당 구멍의 완벽 판정만 무효로 한다.
- 판정 단위: 철판 1판(6구) = 손님 1명에게 서빙되는 1접시. 만족도 변화는 접시 단위로 적용한다(§점수).
  - 완벽 굽기 +10: 6구 모두 익음 2회 적정, 굴리기 3회 성공, 속재료 문어.
  - 덜익음/탐 -10: 해당 구멍이 1개 이상이면 접시당 1회.
  - 함정 재료 -20: 함정 재료 구멍이 1개 이상이면 접시당 1회.
- 서빙: 6구 완성 시 가장 먼저 온 대기 손님에게 자동 서빙(선착순). 예외: 손님이 0명인 페이즈(튜토리얼·P1)는 완성 시 서빙 없이 전환한다.
- 서빙 후 6구는 빈칸으로 초기화되고 마가린부터 다시 시작한다.
- 속재료 트레이: 문어 + 함정 재료(와사비, 생마늘, 지우개, 마시멜로, 고추). 매 판 위치 셔플.

## 손님 대화

- 손님 발화 시 답 버튼 2개가 화면 랜덤 위치에 등장(서로·도구바와 겹치지 않음).
- 좋은 답 +10, 나쁜 답 -10, 시간초과 -10.
- 대화 중에도 굽기 타이머는 진행된다.
- 답 제한시간 5초. 빠른 손님(6s 간격)도 같고 대화 간격만 다르다.
- 문항 선택: 손님마다 성격을 무작위로 정하고, 성격 내 문항은 세션 동안 반복하지 않는다. 난수 시드는 주입할 수 있어야 한다.
- 손님 흐름: 페이즈 시작 시 손님1 입장, 손님 2명 페이즈는 손님2가 3초 뒤 입장. 서빙받은 손님은 리뷰(만족도 → 별점)를 발급하고 퇴장하며, 다음 손님은 2초 뒤 입장한다. 모든 입장(손님2 포함)은 (이 페이즈에서 서빙한 접시 수 + 현재 손님 수) < 페이즈 목표 접시 수일 때만 일어난다. 그래서 마지막 접시를 서빙하면 남는 손님이 없다. 예외: 손님이 0명인 페이즈(튜토리얼·P1)는 완성 시 서빙 없이 전환한다.

## 진행

| 단계 | 손님 | 대화 간격 | 리뷰 |
| --- | --- | --- | --- |
| 튜토리얼 | 0 | - | 완수 시 5★ 리뷰 1개 확정 지급(평균 포함) |
| 본게임 P1 | 0 | - | 미집계 |
| P2 | 1 | 12s | 집계 |
| P3 | 2 | 각 12s | 집계 |
| P4 | 2 | 손님1 6s / 손님2 12s | 집계 |
| P5 | 2 | 각 6s | 집계 |

- 손님 수는 동시 손님 수다. 예: P2는 손님 1명을 순차 교체하며 2접시를 서빙한다.
- 페이즈 전환: 서빙한 접시 수 기준. P1 1판(서빙 없이 완성 수), P2 2, P3·P4·P5 각 4. P5 종료 시 세션 결과로 간다.

### 튜토리얼

- 화살표 + 상단 안내문구로 단계 유도.
- 게이지 적정 구간 넓게, 탐 판정 없음, 시간제한 없음. 수치: 적정 40~100, 게이지는 100에서 정지.
- 굴리기는 타이밍 바 전 구간 성공.
- 순서 외 탭은 무시하고 화살표를 흔든다.
- 함정 재료는 감점 없이 경고 말풍선만 표시.
- 완수 시 5★ 리뷰 카드 → 본게임 P1 진입.
- 세션당 1회(sessionStorage `tutorialCompleted` 플래그). 새로고침 시 스킵.

## 점수

| 항목 | 만족도 변화 |
| --- | --- |
| 시작값 | 60 |
| 좋은 답 | +10 |
| 나쁜 답 / 시간초과 | -10 |
| 완벽 굽기 | +10 |
| 덜익음 / 탐 | -10 |
| 함정 재료 | -20 |

- 만족도는 변화마다 0~100으로 clamp.
- 별점 = clamp(만족도 / 20, 1, 5), 0.5 단위 반올림.
- 세션 점수 = 모든 리뷰 별점의 산술평균(튜토리얼 5★ 포함).

## 콘텐츠

- 손님 성격 4종: 급한 직장인, 수다쟁이 할머니, 까다로운 미식가, 외국인 관광객. 각 10문항(총 40).
- 문항: 손님 대사 / 좋은 답 / 나쁜 답. 나쁜 답은 무례하거나 엉뚱해서 웃기되 혐오·비하 금지. 두 답 길이가 비슷해야 한다.
- 리뷰 코멘트: 별점 구간(1~5)별 성격당 3개. 0.5 단위 별점은 내림한 구간을 쓴다(4.5★ → 4 구간).
- 튜토리얼 안내문구 9개(단계별), 튜토리얼 5★ 코멘트 1개.
